# クソゲーメーカー

～理不尽RPGをつくってためそ～  
企画 Claude × 実装 ChatGPT ／ 第14回「AIでつくってためそ」

本作品は学習・検証目的の非公式作品です。

## 起動

`index.html` が入口です。HTML/CSS/JavaScript・同梱PNGのみで動き、外部通信・外部ライブラリ・ビルド・バックエンドは不要です。GitHub Pagesにはこのフォルダの内容を配置できます。まだ公開していません。

手元の確認用には、appで `python3 -m http.server 8140` を実行し、`http://localhost:8140/` を開きます。このローカルサーバーは開発用です。アプリにサーバー機能はありません。

## 操作

- **つくる**：部品を選ぶ→マップをクリック／タップ。PCはドラッグで連続配置。スマホは1マスずつ。マップは3倍表示（狭幅は2倍）、必要に応じて枠内を横スクロール。
- **設定する**：マスを選び、村人のセリフ（1行＝1ページ）、敵の強さ、宝箱の中身、扉のカギ、階段の行き先などを設定。同じ部品で再クリックしても開きます。
- **道具**：消しゴムは上の部品から、次に地面を草に戻します。塗りつぶしは地面だけ。元に戻すは60操作まで、Ctrl/⌘+Zでも操作できます。Undoでもクリア認証は解除します。
- **マップ**：16列×12行、最大5枚。座標は左上が `x:0,y:0`。主人公の開始位置はゲーム全体で一つ。
- **あそぶ**：矢印／WASD、前方をEnter／スペースで調べる。スマホは十字ボタンと「しらべる」。狭幅では主人公に合わせて横スクロールします。
- **文字送り**：ページが表示し終わると「つぎへ」が押せます。長話と地獄送りは飛ばせません。
- **保存**：編集はlocalStorageに自動保存。タイトルの「つづきからつくる」で復元します。別ブラウザ・別端末への移動はJSONを使ってください。保存が使えない場合は画面に失敗を表示します。
- **共有**：作者テストクリア後だけURL発行可。編集すると認証解除。JSONを読み込んだ場合も再度テストクリアが必要です。URL受信者には作者クリア済み表示を引き継ぎますが、これは改ざん防止の電子署名ではありません。
- **音**：最初はOFF。「音 OFF」を押すとON。Web Audioで効果音とフィールド／戦闘ループを合成します。

## 見本とクリア経路（ネタバレ）

見本は `data.js` に同梱し、同内容のJSONを `samples/` に収録しています。静的ファイルの取得も必要ありません。

| ファイル | 題名 | 評価 | 安全な経路（開始から） |
|---|---|---|---|
| `samples/01-village.json` | はじめての村 | ★1 / 14点 | 上3、右3、上1、右2、下1、右6、上5 |
| `samples/02-cave.json` | やさしい洞くつ | ★3 / 77点 | 右2、上1、右8、上7、右1 |
| `samples/03-castle.json` | ぜったいクリアさせない城 | ★5 / 165点 | 右1、上1、右10、上8、右1。エンカウント時は「たたかう」。敗北時は入口から同じ経路で再挑戦 |

3本ともブラウザで実際に作者テストクリア済みです。コピーして編集すると自分のクリア認証は解除されます。

道なりに進むと、村は見えない壁、洞くつはミミック・落とし穴・あべこべ床、城はミミック・落とし穴・手前のニセゴールに遭遇します。上の表は、それらを避ける経路です。城の主人公はHP30・攻撃8。黒い騎士には負けても先へ進めます。

## JSON形式 `kusoge-maker/1`

実例は `samples/*.json` を参照してください。UTF-8、2MB以内。地面は16文字×12行の文字列配列 `ground` と、1文字から地面IDに対応する `legend`。物は `objects` 配列。物は1マス1個で地面の上に重なります。主人公は `start:{map,x,y}` だけで表します。

マップ番号は **0始まり** です。編集画面の「マップ1」はJSONの `map:0` に相当します。読み込み時は構文・行数・文字数・ID・座標・数値・選択値・物の重複を検査し、元JSONの行と項目を案内します。

### 地面ID

`grass` 草地、`dirt` 土の道、`floor` 石の床、`wall` 壁、`water` / `water_2` 水、`tree` 木、`door` 扉、`stairs` 階段。

扉・階段の設定は同じ座標の `objects` に記載します。`objects` にだけ置いて地面に重ねることも可能です。地面だけの扉はカギ不要、行き先のない階段は移動しません。

### 物／キャラ／仕掛けID

| type | 追加プロパティ | 動作 |
|---|---|---|
| `villager` | `lines:["1ページ","2ページ"]` | 前方を調べて会話 |
| `chest` | `item:"herb" / "sword" / "key" / "rock"` | やくそうは取得時全回復、つるぎは取得時攻撃+5、カギは消費しない |
| `enemy` | `hp:10, atk:3` | 接触／調べると戦闘 |
| `goal` | なし | 接触でクリア |
| `door` | `locked:false` | 調べて開く。trueならカギが必要 |
| `stairs` | `to:{map:0,x:2,y:10}`（必須） | 接触で指定マップ・座標へ |
| `invisible_wall` | なし | 見えない通行止め |
| `pit` | なし | 一瞬穴が見えてマップ1へ |
| `mimic` | `hp:30, atk:8` | 宝箱に擬態。開けると戦闘 |
| `warp` | なし | 全マップの歩けるマスへランダム転送 |
| `reverse` | なし | 踏むたびに操作反転／解除 |
| `loop` | なし | 現在マップの入口へ |
| `fake_goal` | なし | 3秒後にうそが判明し、マップ1へ |
| `oldman` | `lines:["急ぐでない。"]` | 1文字0.5秒。いいえで全ページやり直し |
| `boss` | `allowLose:false` | HP9999、逃走・撃破不可。trueなら敗北後全回復して先へ |

`hero_*`, `pit_edit`, `mimic_edit` 等は画像IDです。JSONの `objects.type` には使用しません。作者クリア済みは `authorCleared`。未知のオブジェクトIDは日本語のエラーにします。

### クソ設定 `kuso`

`encounterRate`: 0〜100（歩いたときの%）／ `textSpeed`: `normal|slow|hell`（25/140/500ms）／ `vision`: `all|near`（3マス四方）／ `walkSpeed`: `normal|slow`（130/550ms）／ `bgmSpeedUp`: boolean（60秒ごと+1倍、最大3倍）／ `reallyConfirm`: boolean ／ `respawn`: `entrance|start`。

### URL

JSON→ `CompressionStream("deflate-raw")` → base64url → `#g=...`。URL全体が8000文字超ならJSON書き出しへ案内。圧縮非対応ブラウザにもJSONを案内します。`localhost` のURLは同じPC内だけの確認用です。公開後にそのページで発行し直せば、友だちに渡せます。

## 判定と復活の補足

- 部品ごとの点数・設定加点・通常部品の減点を内訳表示。25/50/85/120点で★2/3/4/5。
- 入口から復活：HP全回復、同じプレイ内の持ち物・敵撃破・開封状態を維持。最初から：状態をリセット。どちらも時間・死亡数・仕掛け計数は引き継ぎます。手動の「さいしょから」は完全リセット。
- 落とし穴・ニセゴールは死亡数には含めず仕掛け数に加算。同じ仕掛けでも再度かかると加算します。
- マップ1への戻り先は、開始がマップ1なら主人公の開始位置。開始が別マップならマップ1の最初の空き歩行マスです。
- 階段・ワープで着地したマスの仕掛けは連鎖発動しません。いったん離れて踏むと発動します。
- 共有URLの認証は通常操作でのクリア確認です。サーバーや署名鍵はなく、手書きJSON自体の改ざんは防止しません。

テスト記録・判断・動画用集計は親フォルダの `log/` を参照してください。
